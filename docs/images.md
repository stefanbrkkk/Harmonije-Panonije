# Image replacement map

The prototype intentionally uses original CSS/SVG artwork instead of unrelated stock photography.
Replace or add client-approved originals here:

- `hero/hero-bottles.webp` — strongest product composition
- `products/<product-id>.webp` — one clean image per product or category
- `story/founders.webp` — Anita + Laslo or production/garden image
- `ingredients/*.webp` — closeups of honey, lemon, herbs, fruit

Then wire those paths from `src/data/siteContent.ts` or the relevant component.
